FRONT-END WEB PORTFOLIO

FILES
- index.html: main portfolio page
- project-1-landing-page.html: standalone landing-page demo for a fictional beauty studio
- project-2-html-css-fixes.html: interactive before/after visual cleanup demonstration
- project-3-responsive-design.html: responsive fictional product catalog with working category filters
- styles.css and script.js: main portfolio styling and behavior

HOW TO VIEW
1. Extract this folder from the ZIP.
2. Open index.html in a modern browser.
3. Click “View live demo” on each project card to open its standalone page.

HOW TO PUBLISH FREE
Upload all files in this folder to a GitHub repository and enable GitHub Pages from the repository settings. Keep the files together in the same folder.

IMPORTANT
These are independent demonstration projects, not commissioned client work. The catalog uses illustrative products and prices. Replace the sample email address in index.html before publishing. Review and test all code before offering similar work to paying clients.

Contact buttons open Gmail compose in a new browser tab, addressed to samusfiverr@gmail.com. The visitor needs to be signed in to Gmail to send from their account.
